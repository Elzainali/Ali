🚗 Elzain Ali - Portfolio Website
================================

محتويات الملف:
- index.html          → الصفحة الرئيسية (البورتفوليو)
- impressum.html      → الملاحظات القانونية
- datenschutz.html    → سياسة الخصوصية
- style.css           → أنماط التصميم
- fonts/              → مجلد الخطوط (إذا أردت إضافة خطوط)
- README.txt          → هذا الملف

📸 إضافة صورتك:
1. ضع ملف صورتك باسم "Ali.jpg" في نفس المجلد مع index.html
2. يجب أن تكون الصورة بصيغة JPG أو PNG
3. الحجم الموصى به: 400x400 بكسل أو أكبر

🌐 فتح الموقع:
1. فك ضغط هذا الملف
2. افتح "index.html" في المتصفح الخاص بك
3. الموقع يعمل بالكامل بدون إنترنت

🎨 تخصيص الموقع:
- يمكنك تعديل النصوص والألوان في index.html
- تعديل الألوان في القسم :root في style.css
- استخدم أي محرر نصوص (Notepad++, VS Code, إلخ)
